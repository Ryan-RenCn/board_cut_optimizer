## 运行

直接运行 `板优排.exe`。这是 Windows x64 原生单 EXE，不需要 Node.js、Electron、WebView2、Rust 或额外安装 VC 运行库。程序、图标、中文字体和许可证均已嵌入。

目标系统为 Windows 10/11 x64；当前实测为 Windows 11（构建 26200）。渲染使用 OpenGL，需要正常的显卡驱动。保存 PDF 使用 Windows 的 Microsoft Print to PDF 功能；未启用时仍可选择其他已安装打印机。

除 EXE 外的 README、验收记录和 build-info.json 仅是说明/构建信息，可不随程序携带。运行后仍会生成数据库文件，单文件分发不意味着不产生数据文件。

## 新版工作台 UI

已应用经确认的「工业浅色工作台」设计：深色侧栏、绿色主操作、浅色面板与统一矢量导航图标。

- 零件清单：工程说明与目的地统一录入，大窗口增加本单概况；保留键盘连续录入。
- 下拉选项采用紧凑行距，不改变收起控件与表格行高。单行输入框在鼠标或键盘获得焦点时自动全选，可直接替换；再次点击仍可定位光标，不反复打断编辑与中文输入。
- 开料排版：真实排版分组缩略图与主图联动，重复方案合并，试排与未排入状态明确提示。
- 统计报告：首行费用卡片，第二行按「报价明细文本 → 板材总量使用 → 本单报价调整」并排等高展示，小窗口依次纵向排列。用量卡片仅显示使用张数、零件件数、板材实际总面积、零件实际占用面积、含锯缝的未占用面积及面积加权利用率，不再展示分组明细和底部说明；未排入零件不计入。长文本在卡片内滚动，材料税率置于本单报价调整内；逐板计费明细在下方展示。保留逐板调价与恢复自动计价，未完整排入时禁用正式报价输出。
- 全局设置：参数与规则、报价文本模板拆为页签；占位符可点击复制。
- 工程库、确认、关于与打印预览统一样式；打印预览支持选页。
- 小窗口和大缩放使用滚动布局，极窄顶栏把新建、保存与工程库收进「工程操作」。

工作台界面使用真实数据，静态设计稿中的数字没有写入工程。绿色较静态稿略微加深，以确保浅绿色选中背景上的文字达到 AA 对比度。

## 使用已有数据

1. 关闭旧版程序，备份其整个 `data` 文件夹。
2. 先将备份副本放到新 EXE 同级目录试用，不要一开始就对唯一的数据副本操作。
3. 优先读取 `data/board_cut_optimizer.sqlite`；不存在时兼容 `data/smartcut.sqlite`。
4. `BOARD_CUT_OPTIMIZER_DB_PATH` 和旧 `SMARTCUT_DB_PATH` 环境变量仍可指定数据库路径，前者优先。
5. 工程库、草稿、全局库存/设置、税率和手动报价调整兼容原版。旧几何数据保留，但仍不支持 CAD/异形排版。
6. 如发现工程内嵌全局设置，会先通过 SQLite backup API 生成一致性备份，再事务迁移；迁移失败回滚，不用空工程覆盖损坏记录。

不要同时使用多个程序编辑同一个数据库。程序目录须允许写入；否则请显式指定可写的数据库路径。本仓库不再提供旧网页/Electron 程序；只兼容已有 SQLite 数据，不直接迁移浏览器 localStorage。

## 功能与验证

支持库存、零件录入、MaxRects/束搜索、旋转和锯缝规则、后台优化/停止/60 秒超时、排版图与合并、计价/损耗/物流/税率、手工报价、模板、CSV、工程库、打印预览和原生打印。未完成排版禁止正式报告导出，新增零件只继承可用厚度。批量开关统一设置旋转，之后可单独调整，单件设置优先。

仓库仅保留 Rust 实现和 Rust 测试。历史 JSON/SQLite 兼容样例作为静态测试数据保留，构建和测试不依赖 Node.js 或旧版代码。详细验证方法和人工待验项见 `FEATURE_PARITY.md`。

## 已知边界

- 本版采用确认后的新版 UI；egui 原生控件与静态设计稿存在少量排版差异。工程说明统一位于零件清单页，小窗口适当折叠概况并使用滚动区域。
- 真实中文输入法候选框、第三方输入法、实体打印机和完全干净的 Windows 环境仍需人工验证；不能将本次测试视为所有系统场景均已验收。
- 当前 Microsoft Print to PDF 驱动生成的 PDF 视觉输出正常，但部分数字的文本提取可能异常。复制报价请使用应用的“复制文本”或 CSV，而不是从 PDF 反向提取。
- 程序未进行可信代码签名，Windows 可能提示未知发布者。

## 源码构建

仓库根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/build-rust-win.ps1
```

需 Rust stable MSVC x64 工具链、Visual Studio C++ Build Tools 和 Windows SDK。脚本执行 Rust 测试、锁定依赖的 release 构建、PE 依赖检查和原生 GUI 烟雾测试，输出到 `dist/rust-native/`，不打 ZIP，不覆盖用户 data 文件夹。
