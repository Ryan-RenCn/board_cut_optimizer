# 异形件与任意角旋转：证据、实现和计量口径

日期：2026-10-26；板优排版本：1.0.7。

## 已实现的能力

- 以真实外轮廓和内孔描述简单多边形，支持凹口互锁及孔内套件。
- 允许指定任意有限小数角度，例如 `17.3°`；自动模式使用角度步进、边对齐和默认两层局部细化。
- 按真实轮廓检查碰撞、欧氏间距、边距和旋转许可，不用包围框代替异形碰撞。
- 零件行的“轮廓”按钮提供编辑、预览和 L 形示例；轮廓 JSON 导入导出完整保存形状和角度。
- 开料图和逐件回放使用真实多边形及偶奇填充显示内孔，报告列出实际旋转角度。
- SQLite 工程和草稿保留轮廓、孔洞及角度列表。

这些是依据静态逆向线索实现的独立几何算法。没有运行 Solid Edge 做同工程输出对照，**不能宣称已等价还原其完整商业内核**。当前不支持圆弧原语、DXF/SVG 曲线直接导入、异形板材、共边切割或切割工序规划。曲线须预先转换为多边形点列。

## 用户确认的重量和利用率口径

严格沿用长宽计量，不扣异形缺角或内孔：

```text
单件计量面积 = 原始长度 × 原始宽度
异形件未填写长宽时 = 其未旋转轮廓的包围长度 × 包围宽度
每张累计计量面积 = Σ(本张各件计量面积)
每张利用率 = min(100%, 每张累计计量面积 ÷ 整张板材面积)
每张重量 = 库存整张重量 × 每张利用率
平均利用率 = Σ(每张封顶后的计量面积) ÷ Σ(整张板材面积)
```

旋转后变大的包围框不重新增加计量面积。多件互锁导致原始包围框面积累计超过整板时，利用率和重量按整板 100% 封顶；这一规则已由用户明确确认。

计价继续在上述利用率基础上加本单损耗率、应用原 10% 阶梯、利润和切割费规则。几何模块内部使用实体面积进行三角化验证与放置评价，**不把该内部面积作为计量、报价或重量用量**，界面及报价不展示“净用量”。

例：500×400 板、整张40 kg；400×300 外框带300×200孔，加150×100小件，全部排入同张。计量面积仍为 `120000+15000=135000 mm²`，利用率67.5%，重量27 kg，不按扣孔后的面积计重。

## 板优排实现步骤

### 1. 校验轮廓

`polygon-geometry.mjs:normalizeShape` 接收：

```json
{"outer":[[0,0],[100,0],[100,40],[40,40],[40,100],[0,100]],"holes":[]}
```

去除重复闭合尾点和连续重复点，拒绝零面积、自交、折返、孔洞越界、孔重叠或接触。每件全部轮廓最多256个顶点，坐标绝对值和尺寸最多1,000,000 mm。整体平移到包围框左上原点。

### 2. 生成角度

`rotationCandidates` 遵守全局和单件旋转许可。自定义角度优先，不会擅自插入其他角度；禁转时仅0°。普通旧矩形默认仍0°/90°，异形自动模式默认15°步进并加入轮廓边对齐方向。

`transformShape` 按任意实数度旋转全部点，随后把旋转后包围框左上角定位到候选位置。返回真实板面轮廓 `placedShape`，同时保留实际 `angle` 和显示用包围尺寸。

### 3. 构造非碰撞位置图

`polygon-nesting.mjs` 使用配置空间禁入域：固定实体 A、移动实体 B 的平移禁区为 `A ⊕ (−B)`。

1. 用含孔 Earcut 三角化两个实体，并校验三角面积总和与实体几何面积一致。
2. 对每个三角形对，将9组顶点差取凸包，得到该凸形对的 Minkowski 差。
3. 用 Clipper 合并所有凸形禁区。孔洞已在三角化时排除，因此不会把整个外包围矩形当作实心障碍。
4. 有间距时对禁区做圆角扩张；把禁区平移到已放件位置。
5. 从板面可行参考点域减去禁区，取边界顶点，并补充真实顶点接触和板边候选。参考域退化为线/点时仍保留精确接触候选。

这里是独立的三角分解 NFP 实现，没有直接调用商业 DLL，也没有声称原库使用完全相同的三角分解方法。Earcut 和 Clipper 分别来自其[官方仓库](https://github.com/mapbox/earcut)与[库文档](https://github.com/junmer/clipper-lib/blob/master/Documentation.md)；源码及完整许可随应用离线打包在 `vendor/`。

### 4. 最终几何复核

Clipper 配置空间使用0.0001 mm整数刻度；圆角扩张使用0.001 mm弧近似容差。这些数值只用于候选生成，不作为最终的碰撞许可。

每个候选还必须通过 `shapesOverlap` 对原始双精度轮廓的边界相交、实体包含和最小线段距离检查，以及板面边距检查。零间距下允许纯相切；相同轮廓、重合实体和不足间距均拒绝。孔内零件还须与孔边保持所设间距。

### 5. 局部角度细化

无自定义角度且允许旋转的异形件，在当前最佳角周围取 `δ=步长/2`，尝试 `[-2δ,-δ,+δ,+2δ]`，下一层再将δ减半。默认两层，最多四层。

这采纳了原库可观察到的局部细化结构，但候选评分和全局调度是本项目实现。它能搜索非步进角和非整数角，**不代表遍历了无限连续角度，也不保证全局最优**。

### 6. 多板选优及预算

只要工程有异形或显式角度列表，进入真实轮廓路径；纯旧矩形保持原组合优化路径。快速模式比较一种排序/放置策略，深度模式比较面积、长边排序及左下优先、紧凑包络两种策略。

单板默认最多100,000次候选复核；达到预算停止额外候选评估，并明确记录 `budgetExhausted`。每次 Minkowski 运算限制4096个三角对，总三角对上限250,000；超限时退为接触候选并记录 `limited/fallbacks`，仍执行真实碰撞复核。几何缓存各最多256项。

这些是工作量保护，不是整个工程的硬耗时保证。受限搜索可能多用板材，不能以“放不下”证明所有连续角度都不可行。

### 7. 保持原计量、报价、保存和显示

引擎内部放置搜索面积与对外计量面积分开。`measurementArea` 是每张原长宽面积累计，`usedArea` 是按整板封顶的计量面积，`usage` 和重量依此计算；真实轮廓只参与摆放。

形状与角度随工程保存。相同排版合并键包含真实轮廓和角度，避免把同包围尺寸的不同形状误合并。SVG路径使用 `fill-rule="evenodd"` 显示孔洞，逐步回放显示实际小数角。

## 使用方法

1. 先维护板材库存并录入零件的数量、材质和厚度。
2. 点击该行“轮廓”，外轮廓每行输入 `x,y`；多个内孔以空行分隔。可先载入L形示例。
3. 指定角度可填 `0,17.3,90`；留空使用自动模式。矩形也可只指定角度而不填写轮廓。
4. 点击“开始优化”，在“开料排版”查看真实轮廓和逐件回放。
5. 异形与角度数据使用“导出轮廓 JSON”备份；四列CSV不能保留这些字段，因此含此类信息时会提示改用JSON。

示例文件：`examples/异形轮廓示例.json`。导入时空材质采用库存第一个材质；厚度不匹配会留空，需先选择可用库存。

## 验证结果

- `npm test`：14组全部通过，包含原矩形、报价、税率、物流及SQLite回归。
- 凹L形与方块在包围框重叠情况下排入同板。
- 框内孔可放小件，仍留足锯缝；孔洞不会减少计量或重量。
- 120×10矩形以45°进入100×100板；显式17.3°保持不变。
- 三角形在粗角候选下无法进入100×100板，局部细化后以139.06505117707798°进入。
- 无效轮廓、无效角列表、禁转、预算及确定性检查通过。
- 几何碰撞还与 Clipper 的180组随机布尔交集作独立对照。
- 实际 Electron 界面验证通过：编辑器拒绝自交、显示内孔路径和17.3°、逐步回放、轮廓保存；500×400/40kg示例显示67.5%和27kg。

测试运行方式：`npm test`；实际界面检查：`npx electron tests/ui-polygon-smoke.mjs`，使用独立内存数据库，不访问用户工程库。
