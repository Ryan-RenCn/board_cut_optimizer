## 1.0.11补充：自定义顶点上限

全局设置`maxShapeVertices`替代历史固定256上限，默认256，至少3的整数。CAD解析器通过`maxVertices`参数传递到曲线离散、拼接与外环/孔洞验证；轮廓编辑、JSON导入导出、引擎校验及排版使用同一设置。点击保存全局设置后持久化。下文256点描述为旧版默认，不再是固定最大值。文件总点数和搜索工作量限制保持独立。

## 1.0.9补充：DWG

DWG现可在Windows直接选择。新模块`dwg-convert.mjs`以独立进程调用GNU LibreDWG 0.14的`dwg2dxf.exe`，仅通过文件输入/输出，然后复用下文DXF流程。转换器、DLL、许可和完整对应源码随便携包附带，无需安装CAD。上传与转换限10MB，30秒超时，固定参数不执行shell；临时文件结束后清理。来源记录保留DWG文件名和签名。

真实R2000、R2010、R2018圆形样例转换及尺寸回归通过；2007样例出现上游解码ERROR，程序拒绝导入。DWG复杂实体、代理对象、损坏文件仍可能不支持；不承诺所有版本和对象完全兼容。下文“DWG不支持”等描述属于1.0.8历史范围。上游版本与校验值记录在tools/libredwg/NOTICE.md。

- `Import.AutoCadFileHandler` / `Import.AutoCadModel` 共选取32个方法、656条调用边。实体分派方法 `0x06000093` 有13个类型分支。
- 程序引用 WW CAD 4.0.38.30；全程序集引用包含 `DxfReader.Read`、`DwgReader.Read`。由于混淆代理，不能据此声称已还原读取器完整调用顺序。
- `0x06000092` 读取块插入点、基点、旋转、缩放和子实体；`0x06000095` 读取线段端点；`0x96–0x98` 读取圆弧、圆和椭圆参数；`0x99` 读取样条控制点、拟合点、节点、权重和次数；`0x9a` 读取多段线顶点、bulge及闭合标志。
- 部分拟合多段线方法包含 NotImplementedException，不能宣称原软件无限制支持所有 CAD 图元。
- 图像导出 API 的程序集引用只说明存在相关能力，不证明原软件零件行的缩略图行为。

## 板优排实现步骤

1. 检查 ASCII DXF 组码结构、实体类型和大小；DWG、二进制DXF及未支持的加工图元明确报错。
2. 离线 dxf-parser 1.1.2 解码实体，读取图纸单位并转换为毫米；可手动覆盖单位。
3. 递归展开 INSERT 的基点、缩放、旋转、插入点和阵列；将CAD的Y向上坐标转为界面Y向下坐标。
4. 线段保留端点；bulge、圆弧、圆、椭圆按弦误差离散，并加入解析极值点，避免包围尺寸因采样缩小；完整非有理1–3次样条按Bezier段细分。
5. 按端点容差拼接闭合环，拒绝开放/分叉/重复/相交边界；按包含层级的奇偶区分外环、内孔和孔内独立零件。
6. 校验轮廓，计算包围长宽，生成零件及来源记录；先显示导入预览，确认添加后保存到现有SQLite草稿。
7. 每行显示真实SVG小图，采用evenodd填充显示内孔；普通矩形也有小图，空白尺寸显示占位；点击小图进入轮廓编辑。
8. 导入件使用现有异形排版引擎；利用率、重量和报价仍按长×宽计算，整板100%封顶，不使用净面积。

## 范围和验证

这是依据静态证据和DXF规范独立实现的兼容流程，不包含原厂DLL，不宣称与Solid Edge导入器完全等价。当前支持XY平面显式边界；有理/拟合点样条、3D、非默认法向、带宽多段线等需先在CAD中转为二维闭合多段线。HATCH、文字、标注等只作为注释忽略并显示提示，不自动从填充推断加工边界。每个零件包含内孔在内最多256点。

示例：`examples/CAD-轮廓与内孔示例.dxf` 应得到120×80带孔板、100×60 L形件。自动回归覆盖单位、块变换、线段拼接、孔内岛、来源持久化及错误拒绝；实际Electron验收脚本为 `tests/ui-cad-smoke.mjs`。

参考：[dxf-parser原项目](https://github.com/gdsestimating/dxf-parser)、[Autodesk DXF POLYLINE规范](https://help.autodesk.com/cloudhelp/2023/ENU/AutoCAD-DXF/files/GUID-ABF6B778-BE20-4B49-9B58-A94E64CEFFF3.htm)。第三方源码与许可在vendor目录。
